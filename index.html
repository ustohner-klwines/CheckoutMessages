Checkout Shipment Messaging

Design references for the checkout messaging redesign. Every page carries a toolbar at the top — that toolbar is not part of the design, it switches between scenarios so one page can show many.

The problem these address: a shopper whose order splits across warehouses sees several near-identical blocks and is never told how they relate — or, in the case of New York stock, that it is going into a RareStorage account rather than to their door.

Desktop only in this round. Mobile is round 2.

Reading these

Every scenario is linkable. The toolbar writes to the query string, so any state can be sent to someone directly — the chips above are just examples.

Order review and receipt are not built yet. Their toolbar links are present and will 404.

Some copy is still placeholder. The pickup example's right-hand “Pickup Information” panel, and the store's street address, are stand-ins pending real content.

The decision record is deliberately not published here. NOTES.md holds the copy rules, the deviations from the requirements doc and the open questions, and it lives in the design-system repo only — this site is public.
